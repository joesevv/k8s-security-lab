Cluster: kind seclab (context kind-seclab), Kubernetes v1.35.5.
Admission controller: Kyverno v1.18.2 (reg.kyverno.io/kyverno/kyverno:v1.18.2).
Policy: ImageValidatingPolicy require-keyless-signed-ghcr
(policies/supply-chain/require-signed-images.yaml), validationActions [Deny],
failurePolicy Fail, matching images under the glob
ghcr.io/joesevv/k8s-security-lab/* in namespaces demo + demo-kyverno-only, on
pods, pods/ephemeralcontainers, apps/v1 workloads and batch/v1 jobs.

Threat blocked: "an attacker runs an image this project never built." Registry
allow-listing (phase 2b) only proves WHERE an image came from, not WHO built
it — anyone with push access to the org, or a compromised CI step, can put a
tampered image at a trusted path. A cosign keyless signature binds the image
DIGEST to the OIDC identity of one specific GitHub Actions workflow on one
specific ref, recorded in the Rekor transparency log. Kyverno verifies that
signature at admission, so an image that did not pass through the trusted
producer never runs.

SCOPE OF THE CLAIM: a signature attests PROVENANCE, not safety. It proves who
built the bytes and that they have not changed since. It says nothing about
CVEs — Trivy runs report-only in CI (exit-code 0), so a vulnerable image is
still signed and still admitted. See runbooks/phase-4-supply-chain.md.

WHAT CHANGED SINCE THE PREVIOUS CAPTURE: the two-job (build-scan || sign) shape
of .github/workflows/supply-chain.yml has now EXECUTED, and the cluster has been
re-pinned onto its output. The earlier capture said the split had never run and
that the workflow's cosign verify self-check "proves nothing yet." That is no
longer true — see the CI PRODUCER section below. Both halves of the chain are
now demonstrated: cosign verified the signature in CI, and Kyverno verifies it
again at admission. Read the CI half precisely — that cosign verify runs AFTER
the image and the signature are already in GHCR, so it gates nothing. It is a
post-publication self-check that fails the pipeline: it cannot stop a bad
signature from being published, only from shipping silently green.
