============================================================
A) BASELINE (the vulnerability) — a normal Secret's `data` is ONLY base64
ENCODING, trivially reversed. Uses a THROWAWAY value, not the real secret.
$ kubectl create secret generic example-plain -n demo --from-literal=example-key='hello-not-a-real-secret' --dry-run=client -o yaml | grep 'example-key:'
$ echo <that-base64> | base64 -d
============================================================
  example-key: aGVsbG8tbm90LWEtcmVhbC1zZWNyZXQ=
$ echo aGVsbG8tbm90LWEtcmVhbC1zZWNyZXQ= | base64 -d
hello-not-a-real-secret

=> base64 != encryption. This is exactly why a plaintext Secret in Git is a
full compromise, and why the sealed artifact below is different.
