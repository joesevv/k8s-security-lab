signed-app

This is the phase-4 supply-chain demo application for the k8s-security-lab.

This image is built, scanned (Trivy), SBOM'd, and cosign keyless-signed by GitHub Actions. Kyverno's ImageValidatingPolicy admits it to the cluster only when the keyless signature from this repo's workflow identity is verified.

If you can read this, the signed image is serving on port 8080 as uid 101 (non-root).
